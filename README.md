# PolyZoom

Dead simple zoom mod for Minecraft 1.8.9 (Ornithe/Fabric), configured through OneConfig.

Hold <kbd>C</kbd> to zoom, <kbd>F6</kbd> for the secondary zoom, scroll while zooming to go further.

## Options

PolyZoom maintains compatibility with Zoomify's configuration file, and supports everything it does
(besides the irrelevant spyglass options).

Configure keybinds in vanilla's options menu, and zoom settings in OneConfig.
